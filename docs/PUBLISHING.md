# Публикация на GitHub

[Карта документации](README.md) · [Результаты проверок](TESTING.md)

## Подготовленное состояние

Исходники, `public/media/`, lock-файл, документация и настройки CI предназначены для хранения в Git. `node_modules/`, `dist/`, логи, локальные `.env` и настройки редакторов исключены через [.gitignore](../.gitignore). Правила перевода строк и бинарных файлов находятся в [.gitattributes](../.gitattributes), отступов — в [.editorconfig](../.editorconfig).

Репозиторий: [fesoo/media-feed-test-task](https://github.com/fesoo/media-feed-test-task), основная ветка — `main`, видимость — public. Основной README оформлен на английском для портфолио; подробная техническая документация — на русском. Исходники и демоматериалы опубликованы через подключение GitHub.

Поле `private: true` в `package.json` защищает от случайной публикации npm-пакета; видимость GitHub-репозитория задаётся отдельно.

## Состояние публикации

- Создан отдельный публичный репозиторий `fesoo/media-feed-test-task` для портфолио.
- Демо заменено собственными синтетическими материалами; см. [MEDIA.md](MEDIA.md#демо-файлы).
- Выбрать лицензию, если планируется разрешить повторное использование кода. `LICENSE` намеренно не добавлен без решения владельца.
- Состав исходников проверен; чистая установка и сборка прошли локально и на GitHub.

Первичная проверка исходников не обнаружила распространённых шаблонов ключей/токенов и файлов больше 50 MiB. Это проверка состава проекта и известных шаблонов, а не гарантия отсутствия любых секретов.

## Проверка локально

```bash
npm ci
npm run build

git status --short --untracked-files=all
git ls-files --others --exclude-standard
```

После добавления выбранных файлов в индекс:

```bash
git diff --cached --stat
git diff --cached --check
```

В репозиторий включены `package-lock.json` и все демофайлы. Зависимости и результат сборки исключены. Адрес origin: `https://github.com/fesoo/media-feed-test-task.git`.

## GitHub Actions

[CI workflow](../.github/workflows/ci.yml) запускается на push, pull request и вручную:

1. Получает исходники с правами `contents: read`.
2. Устанавливает Node.js из `.nvmrc`, включает npm cache.
3. Выполняет `npm ci`.
4. Выполняет `npm run build`, включая TypeScript.

У workflow нет deploy-шагов, публикации пакета или разрешений на запись в репозиторий. Используемые actions описаны в официальных репозиториях [checkout](https://github.com/actions/checkout) и [setup-node](https://github.com/actions/setup-node). Их теги указаны в workflow; обновление этих версий выполняется отдельно.

[Первый запуск CI](https://github.com/fesoo/media-feed-test-task/actions/runs/43820847036) завершился успешно 16 ноября 2026 года. При следующих изменениях проверяйте результат нового запуска в Actions. Успешная сборка не означает прохождение UI/E2E-тестов: они пока не добавлены.

## Размещение исходников и развёртывание сайта

Публикация репозитория не включает хостинг приложения. Для обычного статического хостинга нужно собрать проект и опубликовать содержимое `dist/` с выдачей по корневому пути сайта. Vite preview служит локальной проверкой сборки.

**GitHub Pages по адресу вида `/repository/` пока не настроен.** Сейчас Vite использует корневой base, а URL медиа в `mockApi` начинаются с `/media/`. Для размещения в подпапке нужно согласованно задать `base` и строить URL медиа через `import.meta.env.BASE_URL`, затем проверить сборку по этому пути. Автоматический deploy workflow следует добавлять после выбора места размещения.
