# Проверка проекта

[Карта документации](README.md) · [Ограничения](PROJECT_REVIEW.md)

## Что проверяется сейчас

В проекте есть команды проверки TypeScript и сборки. Unit-, component- и E2E-тестов, test runner и команды `npm test` нет. CI выполняет чистую установку и `npm run build`, включающую проверку типов.

```bash
npm ci
npm run typecheck
npm run build
npm run preview
```

`typecheck` удобно запускать отдельно во время разработки; `build` уже включает `tsc -b`, поэтому CI не дублирует этот шаг.

## Ручная проверка

Сценарии ниже — инструкция для проверки, а не перечень пройденных тестов. Начните с чистых данных приложения, см. [разработку](DEVELOPMENT.md#локальные-данные-и-диагностика).

| Сценарий | Ожидаемое поведение / предмет проверки |
|---|---|
| Открыть ленту | Первая страница, попытка autoplay без звука |
| Один свайп вверх/вниз | Переход к соседу, без пропуска нескольких индексов |
| Колесо и длинная инерция трекпада | Проверить число переходов и момент снятия блокировки |
| Вернуться к предыдущему | Позиция начинается с нуля |
| Короткий тап, затем удержание | Пауза/play; через 420 мс — 2×, при отпускании — 1× |
| Лайк и кнопки | Лайк меняется без pause; кнопки не запускают drag |
| Таймлайн | Меняет позицию, буфер и прогресс отображаются |
| Стрелки, Space, M при фокусе ленты | Навигация, playback и muted |
| Те же клавиши на кнопке и range | Проверить конфликт с обработчиком ленты |
| Выбрать 2, 3, ∞ | Соответствующее число повторов; настройка переживает reload |
| Дойти до последних трёх записей страницы | Дозагрузка, до 45 записей в каталоге |
| Дойти до конца каталога | Нет выхода за границы, отсутствие следующей страницы |
| Перезагрузить страницу | muted и индекс сброшены, repeat mode и история сохранены |
| Проверить окно в DOM | Не более девяти карточек и трёх video |
| Повернуть экран, изменить размер | Сохранение активной карточки и правильного выравнивания |
| Включить reduced motion | Навигация без smooth-перехода |
| Network Information API недоступен | Профиль unknown, лента продолжает работать |

Для проверки реального звучания замените MP4 файлом с аудиодорожкой. Для HLS добавьте доступный поток в `hlsUrl` и отдельно проверьте native HLS, MSE и отсутствие обоих механизмов.

## Проверка отказов

- Заблокируйте MP4-запрос: проверьте retry, постер, сообщение ошибки, ручной повтор и переход к соседу.
- Смоделируйте отказ первой страницы и следующей страницы отдельно. `mockApi` штатно не генерирует эти ошибки; простое включение Offline не создаст отказ локального таймера API.
- Смоделируйте ошибку лайка и серию быстрых лайков: проверьте rollback и итоговую согласованность cache с каталогом.
- Запишите некорректную историю в localStorage: ожидается безопасное чтение без остановки приложения.
- Прервите pointer-жест системным событием cancel: проверьте, что не возникает нежелательного действия.
- Для HLS проверьте сетевую ошибку, ошибку декодирования, исчерпание попыток и повтор по кнопке.

## Дальнейшие автоматические тесты

| Уровень | Приоритетные сценарии |
|---|---|
| Unit | Границы индекса, swipe threshold, preload, правило просмотра и лимит истории |
| Component | Tap/long press/cancel, timeline, reset позиции, keyboard-controls |
| Integration | Пагинация, ошибки и retry, конкурентные лайки и rollback |
| E2E | Touch/wheel, повторы, resize при первой загрузке, reduced motion |
| Performance | Длительный просмотр, число video/HLS instances, память, трафик, dropped frames |

Проверки на iOS Safari и Android Chrome, screen reader, CPU/network throttling и 30–60 минут просмотра остаются отдельной работой. Целевые показатели из [roadmap](ROADMAP.md) не являются измеренными результатами.
